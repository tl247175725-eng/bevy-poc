# 十三、天气公理

> 2026-06-20 确认。五变量物理模型，Clausius-Clapeyron 为核心。

---

## 1. 设计原则

天气不是独立系统——是与 Consume/Strike/Move 同构的公理：

```
标签描述身份 × 公理处理交互 → 行为涌现
温度/湿度 × 天气公理 → 云/雨/风/雷涌现
```

- 天气状态存在于每个格子的"大气卡"中
- 没有全局天气管理器——每个格子自己计算
- 卡牌修改公理输入变量 → 天气自动变化
- 全局天气 = 所有格子天气的聚合涌现

## 2. 五变量

| 变量 | 符号 | 物理公式 | 来源 |
|---|---|---|---|
| 温度 | T (K) | 辐射 + 扩散 + 潜热 | 太阳 + 地表 + 海拔 |
| 饱和水汽压 | e_s (Pa) | Clausius-Clapeyron(T) | 从 T 推导 |
| 实际水汽压 | e (Pa) | 蒸发 - 凝结 | 水体蒸发 + 扩散 |
| 相对湿度 | RH | e / e_s | 推导 |
| 风 | W (m/s, rad) | 温度梯度 → 气压差 | 推导 |

## 3. 核心公式

```
Clausius-Clapeyron:
  e_s = 611.3 × exp(5423 × (1/273.15 - 1/T))

蒸发:
  d(e)/dt = k × (e_s(T_water) - e) × (1 + 0.1 × wind_speed)

凝结:
  RH > 1.0 → 过饱和 → 凝结成云
  云 > 0.3 + 抬升 > 0.1 → 降水

潜热反馈:
  凝结释放 Lv = 2.5×10⁶ J/kg → 加热大气 → 驱动更强对流

闪电:
  云厚 > 0.5 + T < 0°C + 对流强 → 电荷分离 → 闪电

雾:
  RH > 85% + 风速 < 5m/s + 露点差 < 3K → 雾
```

## 4. 卡牌介入

卡牌不写脚本——修改天气公理的输入变量：

```rust
// 寒冬卡
Card { modifiers: [("temperature_mod", -30.0), ("humidity_mod", -500.0)] }

// 暴雨卡
Card { modifiers: [("humidity_mod", +2000.0), ("lift", +0.8)] }

// 雷暴卡
Card { modifiers: [("humidity_mod", +1500.0), ("convection", +2.0)] }
```
