# 术语表（项目特有概念）

| 术语 | 定义 |
|---|---|
| 叠加域 | 多标签同时存在->逻辑域叠加->新意义涌现。不是显式定义的 |
| 哲学僵尸 | AI不"思考"，只做 状态->需求->匹配->执行 的对应 |
| 同构 | 游戏抽象和现实结构原理一致。搬运结构，不搬运细节 |
| 三根柱子 | 标签(形态) + 元数值(强度) + 元动作(变化)。世界的全部 |
| 保结构映射 | 不定义"草原"，分别处理温度/降雨/海拔->交互产生草原 |
| 公理 | 纯函数，只答"能不能"。compose/traverse/perceive/transform |
| 元动作 | 25个原子行为。物理11+信息4+生物3+心智3+社会2+超自然2 |
| 元数值 | A层(必须)+B层(强推荐)。所有数字的唯一来源 = meta_values.rs |
| BodyProcess | 统一身体过程框架。磨损/生长/感染/衰老/癌变=同一模型不同参数 |
| ADD | 积温日(Accumulated Degree Days)。法医学腐烂公式 |
| 格子资源 | 植物=格子上的数量卡，不是独立实体 |
| handoff | 设计->代码的合约。三段：架构计划+架构反馈+智能验收 |
| 合约 | handoff确认后=合约签了。合约外的内容不能写，卡住回来问 |
| EO范式 | 可执行本体论。不问"该怎么行动"，问"什么是真的，什么变得可能" |
| 铁律 | 不可违反的规则。写在 memory/FACT.md 中 |
| 标签纯度 | 标签必须通过5条验证：无物种名、可转移、可组合、收敛进化验证、行为闭包 |
